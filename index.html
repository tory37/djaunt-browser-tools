Djaunt Host Swap

Chrome Firefox

Rewrites hosts to other hosts before the request resolves, keeping the path, query string and fragment byte-identical. Point a fixed launch URL at a branch deploy without hand-editing a URL that carries live auth tokens.

  • Holds as many swaps as you like, enabled one at a time
  • Redirects before DNS resolves — the original host is never contacted
  • Rules persist across browser restarts

Djaunt Query Params

Chrome Firefox

Removes and adds query string parameters on a chosen domain before the request resolves, leaving the scheme, host, path and fragment untouched. Flip flags and locales on a launch URL you cannot hand-edit.

  • Holds as many tweaks as you like, each toggled on its own
  • Applies per domain — no expiry, no tab or session scoping
  • Rewrites before the request resolves, so nothing is ever double-fetched

Djaunt Tab Volume

Chrome Firefox

Sets the volume of each tab from 0 to 100 percent of the system volume, with an option to save that level for every tab on the same domain.

  • Per-tab level, or "keep for this domain" to apply it site-wide
  • Covers both media elements and Web Audio playback
  • Attenuates only — never boosts past the system volume

Djaunt Dark Mode

Chrome Firefox

Forces a dark color scheme on any site, skipping pages that already look dark. Turn it on globally, or override it per domain for the rest of the browsing session.

  • Detects an already-dark page by its background luminance
  • Global switch persists; per-domain overrides last for the session
  • A storage change reaches every open tab instantly

Djaunt Color Picker

Chrome Firefox

Picks any on-screen color, converts it between hex, RGB, HSL and OKLCH, checks WCAG contrast, and builds CSS gradients — a ColorZilla alternative with no host permissions at all.

  • Uses the browser's native eyedropper, with a pixel-accurate fallback picker
  • WCAG contrast checker and a linear/radial gradient builder built in
  • Zero host permissions — the fallback only ever sees a screenshot you asked for

Djaunt Net Mock

Chrome Firefox 128+

Intercepts the page's fetch and XMLHttpRequest calls and answers the ones you choose with a response you wrote — a mock body, a forced 500, a delay, or a hard failure. No server to stand up, no app code to touch.

  • Match by URL glob or regex and method; mock, fail, or pass a request through
  • A window.djauntMock API, so an agent installs a rule in one line
  • A match log showing what was mocked, failed, passed or skipped, and why
Download .zip
