Privacy Policy

Covers every extension published from tory37/djaunt-browser-tools — Djaunt Host Swap, Djaunt Query Params, Djaunt Tab Volume, Djaunt Dark Mode, Djaunt Color Picker, and Djaunt Net Mock.

Short version

None of these extensions collect, transmit, sell, or share any data, anywhere, ever. Nothing you do in them is sent to a server — there is no server. Everything each one needs to remember is stored locally in your own browser via the standard chrome.storage/browser.storage API, and never leaves your device.

What each extension actually touches

ExtensionReads or acts onEver leaves your browser?
Host Swap Request URLs on hosts you configure, rewritten locally via declarativeNetRequest before the request is sent. No.
Query Params Request URLs on domains you configure, edited locally the same way. No.
Tab Volume The audio level of the tab you're on, adjusted locally in-page. No.
Dark Mode The page's own rendered colors, to decide whether to apply a dark filter. No.
Color Picker Pixels you explicitly click on screen, to read a color value. Requests no host permissions at all. No.
Net Mock The page's own fetch/XMLHttpRequest calls, to answer the ones you've configured a rule for with a response you wrote. No.

Why some of these ask for access to every site

Host Swap, Query Params, Tab Volume, Dark Mode, and Net Mock request permission to act on any site (<all_urls>) because what site they act on is something you choose per extension, at install time you haven't told them which sites yet. That permission is used only to perform the specific, local behavior described in the table above — rewriting a URL, adjusting volume, applying a color filter, or answering a mocked network call — never to read, log, or transmit page content, browsing history, or any other data.

Analytics, ads, and third parties

None of these extensions include analytics, telemetry, crash reporting, ads, or any third-party script or service of any kind.

Changes
